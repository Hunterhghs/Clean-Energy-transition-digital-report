## Metadata

The page embeds full metadata for search and social:

- Standard `<meta>` tags (author, publisher, description, keywords)
- Dublin Core (`DC.creator`, `DC.publisher`, `DC.date`)
- Open Graph (`article:author`, `article:publisher`, `og:site_name`)
- Twitter Card
- JSON-LD `Article` schema with `author: Hunter Hughes` and `publisher: H Heuristics`

## Deploy via GitHub Pages

1. Push this repository to GitHub (default branch `main`).
2. On GitHub: **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, select branch `main`, folder `/ (root)`.
4. Save. The site is served at:
   `https://hunterhghs.github.io/Clean-Energy-transition-digital-report/`

## Local preview

```bash
python3 -m http.server 8000
```
